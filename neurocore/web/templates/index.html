Conexão e chave de API

O modo Local funciona sem chave, mas é apenas uma simulação. Para respostas reais, análise de imagens e geração de imagens, escolha um provedor e informe sua chave de API.

Sem marcar, a chave fica só nesta aba e some ao fechá-la. Ela é enviada apenas ao servidor do NeuroCore, que a usa para chamar o provedor e não a grava em disco. Use chaves com limite de gasto.
Este servidor exige um token para usar a API.
